# Quiz Test Application in C

## Project Description
The Quiz Test Application is a console-based application developed using the C programming language. It allows users to answer multiple-choice questions and calculates the final score based on their answers.

## Objectives
- To practice C programming concepts.
- To create an interactive quiz application.
- To use structures, functions, loops, conditional statements, and file handling.
- To calculate and display the user's final score.

## Features
- Multiple-choice questions
- Automatic answer checking
- Score calculation
- Questions stored in a text file
- Final score display

## Technologies Used
- C Programming
- Structures
- Functions
- Loops
- Conditional Statements
- File Handling

## How to Run

Compile:
    gcc quiz.c -o quiz

Run:
    .\quiz

## Project Files
- quiz.c – Main C source code
- questions.txt – Quiz questions
- .gitignore – Prevents executable files from being uploaded
